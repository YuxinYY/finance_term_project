Add a decision entry for: $ARGUMENTS

Use the template at the top of `docs/DECISION_LOG.md`. Fill every field. For "Source", use only
reference ids from `docs/REFERENCES.md`; if the needed source is not VERIFIED, write the claim as
an assumption and add a TO-VERIFY row for `literature-scout`. For "Evidence", cite an experiment
id and the numbers from a file in `reports/` (give the path). If there is no evidence yet, set
status OPEN and say what experiment would settle it.
