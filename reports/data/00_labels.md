## 5. Recommendation (assumption pending Roger/TA; DECISION_LOG D-002)

- **Primary: start = 6 months, 12-month horizon.** Business reason: for a 31-Dec year-end, accounts are approved within 120 days (180 if the statute allows) and filed within 30 days of approval (R-28, R-29), i.e. public by about end-May, or end-July if extended. A lending decision based on the FY t statement therefore happens from roughly mid-year t+1, and the PD the bank needs covers the 12 months after that. We do not know actual filing dates; this is an assumption.
- Data evidence: 4,237 rows pair a statement with a default 0-6 months after fiscal year-end, before the statement would normally be public; start = 0 would train on these as defaults although a bank could not have scored them with that statement. The share of defaulters that still have the prior-year statement rises with the default month (section 1), so these statements' presence does not show they were available in time.
- Level consequence (same fs_years 2007-2010): default rate 0.0141 at start 6 vs 0.0107 at start 0 (ratio 1.32). The window choice moves the calibration level by about a third: this is why the holdout's window is an OPEN question for Roger/TA.
- Cost: fs_year 2011 is censored at start 6 (window 2012-06-30 to 2013-06-30, data end 2013-05-31: one month short), so only 3 folds (test 2008-2010) and the final model cannot use 2011 statements as labelled data. Under start 0, 2011 is fully observed (4 folds). Fold S0-2011 in walkforward.json keeps that comparison possible.

**Censoring treatments** (for any row whose window is not fully observed):

- *Drop* (ADOPTED for evaluation): unbiased for the years kept; loses the newest vintage. fs_year 2011 under start 6: 183,953 performing rows dropped, 2,357 of them with a default observed in the first 11 months.
- *Keep as 0*: biases the rate down. fs_year 2011 at start 6 would get 0.0128 from 11 of 12 months (x12/11 = 0.0140 if June 2013 looked like the average month); fs_year 2012 at start 0 would get 650 defaults from 5 of 12 months (0.0035), far below the 2007-2011 rates.
- *Keep with y=1 only where observed* (what `make_labels` does by default): only defaults enter the incomplete year, a 100% default rate for that year; never use.
- OPEN option for the final fit only: include fs_year 2011 at start 6 with 11/12 months observed (a small, quantified downward bias, above). Not used in any fold.

**Firm-years after a firm's default**: dropped by rule (`after_default`); the training file has none (0 rows). Rows of a firm after its default would describe a firm that is no longer a performing applicant.
