# Walk-forward 驗證

錨定窗口（anchored window）、特徵固定。以第 t 輪為例。

## 1. 切分

- 訓練集：FY2007 ~ FY(t−1)；測試集：FY(t)。不另外留校準年，校準直接用訓練集本身（步驟 4）。
- 若違約標籤需要觀察期，在訓練集與測試集之間加 gap。
- 標籤可用的年度為 FY2007–FY2011。最早的測試年為 FY2009（訓練集 FY2007–FY2008，至少有一個 fold），最晚為 FY2011，共三輪。

## 2. 調參（只用訓練集）

- 為所選模型定義候選超參數網格（例如線性模型的正則強度、樹模型的深度與學習率）。
- 在訓練集內以 expanding-window 依年份切 fold：訓練 FY2007 → 驗證 FY2008；訓練 FY2007–08 → 驗證 FY2009；依此類推，直到訓練 FY2007 ~ FY(t−2) → 驗證 FY(t−1)。
- 每組超參數在每個 fold 上各跑一次：fold 內 fit imputation、scaling 與模型，再對驗證年算 AUC，避免洩漏。
- 取各 fold 平均 AUC，選最大者。排序能力（power）優先；PD 的水準由步驟 4 的校準負責，所以 log-loss 最多只作為參考。
- fold 只負責挑超參數（若用 early stopping，也決定停止點），與校準、測試無關。

## 3. 重訓

用選定的超參數，在整個訓練集 FY2007 ~ FY(t−1) 上重新 fit imputation、scaling 與模型。

## 4. 校準（用訓練集）

1. 以重訓後的模型對訓練集打分，依分數排序，切成 k 個分位桶，每桶 N/k 家公司（第一桶分數最差）。k 要讓每桶有足夠的違約家數。
2. 計算每桶的違約家數，得到實際違約率。
3. 擬合「分位數 → 違約率」的單調映射曲線（例如 isotonic regression），並記錄每個分位數對應的模型輸出值。
4. 用貝氏 prior-shift 公式，把訓練集的違約率換算成母體違約率：

```
pi* = (T·pi − pi·S·T) / (pi·T − pi·S + S − S·T)
```

- S：訓練集 FY2007 ~ FY(t−1) 合併多年的整體違約率
- T：母體的真實違約率（來源需說明）
- pi：經步驟 3 映射後的 PD
- pi*：校準後的 PD

若 S 與 T 相近，這一步幾乎沒有影響。

模型看過這批資料，所以分數在這裡會比面對新資料時漂亮，曲線會偏樂觀；模型越彈性，偏差越大。測試年的校準圖（步驟 5）可以看出偏差有多大。校準是單調轉換，不改變排序與 AUC。

## 5. 測試（FY(t)，只評估一次）

- 用步驟 3 的模型打分，經步驟 4 的映射與轉換得到校準 PD。
- 報告 ROC/AUC 與校準圖，分既有公司與新公司兩組。「新公司」的定義需註明（例如未出現在訓練資料中的公司）。

## 6. 滾動

把 FY(t) 加進訓練集，重複步驟 1 ~ 5。

## 7. 穩定性

彙整每個測試年的指標，以及每輪選出的超參數。另外逐年檢查校準圖，因為曲線合併了違約率不同的多個年份。

## 8. 最終模型

流程與每一輪相同：用 fold 調參，用截至最新年份的全部資料重訓，並以同一份訓練集校準。

## 設計依據

在模型估計所用的資料上做校準，依據是 Falkenstein et al.（2000）與 Kocagil et al.（2002，附錄 B）。Stein（2007）與 Stein et al.（2003）只說校準資料是假設能代表母體的歷史違約資料庫；RiskCalc 3.1 白皮書沒有說明開發、驗證與校準資料如何劃分。walk-forward 的 fold 切法與用 AUC 調參是我們自己的設計，論文沒有規定。

## 待討論：Bootstrap

**Bootstrap 信賴區間（暫不做，待討論是否加入）。** 偏誤只看校準圖與（平均校準 PD − 實際違約率）的點估計，無法判斷差距是否為雜訊。測試年違約數少時要小心解讀。若之後要加，會是步驟 5 的額外部分，每一輪對測試年跑一次（步驟 1 到 4 不變）：

1. 模型（步驟 3）與校準對應（步驟 4）固定不動，只對測試集重抽樣，所以區間反映的是測試樣本的雜訊，不含重新估計模型的變異。若要衡量後者，得對訓練集重抽樣並每次重跑步驟 2 到 4，成本高很多，這裡不做。
2. 對測試集評分一次，保留每間公司的分數、校準後 PD 與違約標籤。
3. 重複 n 次（例如 n = 1,000）：從測試集的 N 間公司中有放回抽 N 間（同一測試年內每間公司一列），在重抽樣上計算
   - AUC；
   - 偏誤 = 平均校準 PD − 實際違約率。
4. 各取 2.5% 與 97.5% 分位數作為 95% 區間。偏誤看其區間是否包含 0；AUC 區間則說明排序能力有多可信。
5. 既有公司與新公司分開報告：在各組內分別重抽樣，因為新公司組的違約數可能很少，區間會較寬。

注意事項：

- 用一般 bootstrap，不要依違約與否分層。分層會讓每次重抽樣的違約數固定，等於把實際違約率的雜訊拿掉，而偏誤區間要呈現的正是這個雜訊。
- 若合併多個測試年，改依公司 `id` 重抽樣而非逐列，讓同一間公司的各年留在一起。
- 要比較兩個模型時，兩者用同一組重抽樣，取 AUC 差的區間。
- 成本很小，因為不用重新估計模型，只在重抽樣上重算指標。

```python
import numpy as np
from sklearn.metrics import roc_auc_score

def bootstrap_test(y, pd_cal, n=1000, seed=0):
    # y: 0/1 違約標籤, pd_cal: 校準後 PD，皆為測試年資料
    rng = np.random.default_rng(seed)
    aucs, biases = [], []
    for _ in range(n):
        i = rng.integers(0, len(y), len(y))
        aucs.append(roc_auc_score(y[i], pd_cal[i]))
        biases.append(pd_cal[i].mean() - y[i].mean())
    return np.percentile(aucs, [2.5, 97.5]), np.percentile(biases, [2.5, 97.5])
```

AUC 可以直接用校準後 PD 算，因為校準是單調轉換，不改變排序。
