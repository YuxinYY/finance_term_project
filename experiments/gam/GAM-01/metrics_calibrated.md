# GAM-01+CAL metrics (src/common/metrics.py)

EBM main effects only, monotone constraints from the expected-sign table + prior shift to rule e (D-071/D-072, same taus as CAL-01); the 'raw' table here = the own-calibrated PDs before the shift

AR = 2*AUC - 1. Brier = overall probability accuracy (not a calibration measure). Calibration: mean_pd vs observed_dr (calibration-in-the-large, exact binomial p-value) and logistic recalibration intercept/slope (perfect: 0 / 1).
