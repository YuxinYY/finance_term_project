# GAM-01 metrics (src/common/metrics.py)

EBM main effects only, monotone constraints from the expected-sign table (own calibration: Platt slope from inner B, level = training rate; 'raw' table = EBM probabilities without Platt)

AR = 2*AUC - 1. Brier = overall probability accuracy (not a calibration measure). Calibration: mean_pd vs observed_dr (calibration-in-the-large, exact binomial p-value) and logistic recalibration intercept/slope (perfect: 0 / 1).
